# chincharjuin.github.io

Personal website of Char Juin Chin — Senior Data Scientist & AI Engineer at Singapore Airlines.

Single-page static site, no build step. All text lives in `content.js` (edit that file to change words); a small render script (`assets/js/site.js`) fills the page and handles the theme toggle, and all styling is in `assets/css/style.css`. Deployed via GitHub Pages.
